```markdown
- <方法/公式/流程>（源页码 P<xx>）

## 迁移注记

```

## 落盘规则（2026-10-08 首单后按库内实际约定修订，以此为准）

1. **深度精读是一报告一卡**：主卡写入 `D:\我的知识库\02_知识卡\量化因子研报\深度精读\`，命名 `D_<抽取件索引号>_<短标题>.md`（如海通69 抽取索引 041 → `D_041_高频因子现实与幻想.md`）；卡内"原卡 idx"填抽取索引号。
2. **专题衍生卡用日期编号**：独立方法/事实卡放 `02_知识卡\` 根目录，命名 `YYYYMMDD-NN-<短标题>.md`。**编号撞车实测（首单就撞）**：同日其他会话可能已占用 01-14 等号——落盘前先 `ls 02_知识卡 | grep YYYYMMDD-` 查当天最大 NN，顺延取号，禁止从 01 起编。
3. **主卡格式**（库内深度精读约定，优先于上方通用模板）：来源 / 方向 / 原卡idx / 时效警示 + 核心结论 + 可复用方法（落到代码）+ 关键数据 + 与你的策略关联（迁移注记）+ 局限与注意。样例见 `深度精读/D_022_高频因子周期域表现.md`。
4. **档案目录改两处**：`档案目录.md` 的「三、卡片索引」加行（D_ 卡插深度精读区，日期卡按序插入），「二、分类表」量化因子研报行更新计数（深度张数与总数）。
5. 同主题报告已有精读卡（先 grep 档案目录）→ 新卡只补增量并互链，不重写。
6. 出卡数量：主卡 1 张 + 专题卡按独立价值收（首单为 1+3），够格才收，不为凑数硬写。

## 核验表模板（审校分身产出，随复盘记录，不落盘到知识卡目录）

|---|---|---|---|---|
| 1 | | | | 通过/打回+原因 |

## 四项核验清单（每张卡必过）

1. 数字没抄错行（IC 的周期、多头还是多空头收益）
2. 收益口径标明费前/费后（研报默认费前，必须写明）
3. 样本区间和股票池写明（沪深300/中证500/全A，不可跨池搬运）
4. 卡里的话原文真说过——不许归纳过度
